## External integrations not live-tested here

A real Telegram Bot API token, Telegram API ID/hash, and GoFile network access were not available in this build environment. Therefore a real Telegram conversation, Telegram Local Bot API Server, and live GoFile upload could not honestly be certified from this environment.

The implementation follows the current public interfaces verified during development. The Docker image installs FFmpeg, FFprobe, 7zip and unar, and the startup check refuses to start if those executables are missing.
